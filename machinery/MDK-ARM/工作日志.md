## 电机测试汇总（2026-10-01）

### CSGO 写在哪里

- 文件：`../Core/Src/main.c`，`/* USER CODE BEGIN 2 */` 区域，CubeMX 的 MX_TIM2/3/4_Init 和 Motor_SystemInit 成功之后。
- 当前约第 102 行是 `if (CSGO(0, 0) != HAL_OK)`。先在此调用前用 Motor_PIDConfigure 配好两路 CPR、反馈方向、PID 参数，再将这行改成 `if (CSGO(3, 3) != HAL_OK)`，保留后面的错误处理。
- C 代码必须用英文半角括号和逗号：`CSGO(3, 3);`。两个参数依次对应 CN1、CN2。
- while(1) 的 USER CODE BEGIN 3 中持续执行 Motor_Update。目标设置一次即可；不要在更新循环中加入长延时，采样间隔超过 100ms 会停止正在闭环的电机。
- 当前尚未调用 Motor_PIDConfigure，直接把 0 改成 3 会返回 HAL_ERROR 并进入现有 Error_Handler，不会开始闭环。

### 速度数值范围

- 单位是减速箱输出轴 RPM（转/分钟）；3 RPM 是约 20 秒一圈。支持小数，如 3.5f；正负指定方向，0 停止并退出对应闭环。
- 当前软件没有按电机型号设置最大 RPM，仅校验有限浮点数、配置和换向条件。因此不能把浮点数的表示范围当成电机可运行范围，也不是限定 -100～100。
- 实际可用范围是电机在当前电压、负载和 PWM 上限下能稳定达到的转速；型号的额定转速、减速比和实测尚缺，不能给出具体最大值。目标过高时 PWM 会达到配置上限，但实际速度不一定达到目标。
- 3 RPM 很低，是否能平稳运行需实测；当前 10ms 采样时，单个计数对应 6000/CPR RPM，低速反馈可能量化明显，不能用“没看到马上转动”判断程序无效。
- 运行中不能直接从正目标切换为负目标；先 CSGO(0,0)，等待停稳，再给负目标。

### 建议测试顺序

1. 先验证电机及接线：在 main.c 原 CSGO(0,0) 调用处临时替换为 Motor_SetDutyPercent(20,0)，保持返回值检查。这是 CN1 20% PWM 开环测试，不需 PID 配置；20% 是否足以起转取决于实物。再用 Motor_SetDutyPercent(0,20) 单独测试 CN2。测试时让轮子悬空，电机电源匹配额定电压。本文只记录步骤，没有把当前固件改成上电转动。
2. 停止用 Motor_SetDutyPercent(0,0)。调试器观察 encoderA/encoderB 的 position、delta、counts_per_second；未配置 CPR 时 rpm=0 没有测速意义。电机转动但编码器计数不变时，先排查反馈接线，勿启用闭环。
3. 标定输出轴每圈四倍频计数 CPR 和正向反馈符号，配置两路 Motor_PIDConfigure；参数模板见 Motor/PID说明.md。经调参后再用 CSGO(3,3) 测试，观察 encoderA.rpm、encoderB.rpm 与目标。
4. PID 调试时检查 Motor_Update 返回值：HAL_BUSY 是尚未到采样时间；HAL_TIMEOUT/HAL_ERROR 表示异常。零计数不能区分堵转、断线和静止，当前没有堵转保护，不能依靠 PID 自动识别。

### 硬件事实与引脚映射

- 主控：U3 STM32F103C8T6；外部晶振 X1=8MHz，旁边 C14/C15=22pF。
- U7/U8 是 AT8236 功率驱动芯片，接收 MCU PWM，为电机供电并控制正反转。N20 的霍尔 A/B 是反馈信号。
- 用户电机资料：https://wiki.lckfb.com/zh-hans/tjx-tms320f28p550/module/control/n20-hall-encoder-motor.html 。已阅读，确认 A/B 为编码器、M/P 为电机供电端；其 TI 平台代码不可直接用于 STM32。

| 通道         | STM32 引脚 | 实际用途           |
| ------------ | ---------- | ------------------ |
| TIM2_CH1     | PA15       | CN1/U7 的 IN1      |
| TIM2_CH2     | PB3        | CN1/U7 的 IN2      |
| TIM2_CH3     | PA2        | CN2/U8 的 IN2      |
| TIM2_CH4     | PA3        | CN2/U8 的 IN1      |
| TIM3_CH1/CH2 | PA6/PA7    | CN1 霍尔编码器输入 |
| TIM4_CH1/CH2 | PB6/PB7    | CN2 霍尔编码器输入 |

注意 CN2 的 IN1/IN2 绑定次序是 CH4/CH3。早期将 TIM2_CH1/CH2 写成 PA0/PA1 的回答已纠正；实际必须 PA15/PB3 和 Partial Remap 1。
CN1/CN2 六脚分别是：1=AO2/BO2，2=VCC_MISC，3=编码器 CH2，4=编码器 CH1，5=GND，6=AO1/BO1。线束按信号核对，不单凭六针外形或颜色判断兼容。电机功率电源来自 VIN，经 AT8236 输出。

### 当前 CubeMX 设置

- SYS Debug=Serial Wire，禁用 JTAG 以释放 PA15/PB3，保留 PA13/PA14 的 SWD。
- RCC HSE=Crystal/Ceramic Resonator，8MHz ×9，SYSCLK/HCLK=72MHz，APB1=/2。APB1 总线 36MHz，但其定时器时钟为 72MHz。
- TIM2 Internal Clock，CH1～4 PWM mode 1，PSC=0，ARR=3599，Pulse=0，High，有效 PWM 频率 20kHz。生成代码包含 `__HAL_AFIO_REMAP_TIM2_PARTIAL_1()`。
- TIM3/TIM4 Combined Channels=Encoder Mode，TI1 and TI2，PSC=0，ARR=65535，IC1/IC2 为 Rising、Direct TI、DIV1、Filter=6。A/B 四倍频计数，不单独启用 CH1/CH2 PWM。
- 当前编码器 GPIO 是 INPUT、NOPULL。若实际电机输出开漏且无板载上拉，应在 CubeMX 中设置合适的上拉；尚未上板验证输出电气形式。
- 本方案主循环轮询，无需定时器中断或 DMA。Internal Clock 指定时器总线时钟来源，不等于内部 HSI；PWM 可以用外部 HSE 经 PLL 得到的总线时钟。

### 主程序与接口使用

main.c 先执行 HAL_Init、SystemClock_Config、MX_GPIO_Init、MX_TIM2_Init、MX_TIM3_Init、MX_TIM4_Init，然后在 USER CODE 中：

```c
/* CubeMX 的 MX_TIM2/3/4_Init 之后 */
if (Motor_SystemInit() != HAL_OK) { Error_Handler(); }
if (CSGO(30, 30) != HAL_OK) { Error_Handler(); }
/* 主循环中 */
(void)Motor_Update();
```

Motor_SystemInit 在 motor.c 封装两台电机绑定、启动 PWM/编码器、重置计数基准与记录采样时间，失败会回退已启动资源。Motor_Update 封装每 10ms 的采样。motorA/motorB、encoderA/encoderB 都由 motor.c 定义，motor.h extern 声明；encoderTick 为库内 static。初始化函数保持零占空比，当前 main.c 随后调用 CSGO(30,30)，使两台电机持续正方向 30% PWM。

| API/变量                          | 含义                                  |
| --------------------------------- | ------------------------------------- |
| `Motor_SetSpeed(&motorA, 300)`  | CN1 正方向 30% 占空比；参数不是 RPM   |
| `Motor_SetSpeed(&motorB, -300)` | CN2 反方向 30%                        |
| `Motor_Stop`                    | 两输入低，滑行停止                    |
| `Motor_Brake`                   | AT8236 两输入高，刹车                 |
| `Motor_DeInit`                  | 清零并关闭两路 PWM                    |
| `Encoder_Reset`                 | 重建计数基准，清零位置，sign=1、CPR=0 |
| `Encoder_Sample`                | 计算增量、累计位置、计数/秒和 RPM     |

- 调速范围 -1000～1000，越界限幅；正负实际转向依线序确定。换向前停止并等待负载降速，尚未实现自动减速/换向状态机。
- PWM 命令通过 CCR 预装载在下一更新事件生效，更新两通道时保护临界区；所有 API 从同一个主循环上下文调用。
- Encoder_State 中 delta 是采样增量，position 为 64 位累计值，counts_per_second 是计数/秒，rpm 是标定后的输出轴 RPM，valid 表示最近一次采样有效性。
- 默认 counts_per_turn=0，rpm 保持 0 表示未标定，不能据此判断电机静止。获得实际输出轴四倍频 CPR 后，停止状态下设置 encoderA/encoderB.counts_per_turn；反馈符号不符时设置 sign=-1。
- CPR 可由缓慢转动输出轴数圈的累计计数测量。若厂家给电机轴单通道周期数，输出轴 CPR=该周期数×4×减速比；已经四倍频的数据不要再乘 4。
- 每次采样实际变化须小于 32768 个计数。间隔大于 100ms、恰好半计数范围或累计溢出时返回无效；丢失区间不计入位置。避免主循环长时间阻塞。valid 是上次采样结果，不是自动更新的“数据仍然新鲜”标志。
